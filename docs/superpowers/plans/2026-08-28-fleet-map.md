# Fleet Map Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Show every robot the user can see on the Navigation and Map widgets — each placed through its own frame transform, with name labels — while keeping bandwidth to the selected robot's detail.

**Architecture:** The renderer already loops `RobotLayer` per robot; the change is upstream. A `useFleetRobotIds` hook supplies the robot set; the `spatial_transformations` publication and a new `useFrameTransforms` hook resolve one transform per robot; `LocalizationAdapter` transforms each robot with its own transform, skips unplaceable robots (count shown in a note) and only blanks interactions when the *selected* robot has no transform. A ported `RobotName` overlay plus a `robotNames` map layer adds labels. Data sources split into "selected robot: full + live MQTT" and "others: Mongo, low-bandwidth".

**Tech Stack:** Meteor/React (client hooks, `useTracker`), OpenLayers overlays, mocha (app tests on `--port 3100`).

**Spec:** `docs/superpowers/specs/2026-08-28-fleet-map-design.md`

## Global Constraints

- Robot set = all robots from the existing `robots` publication (`useRobots()`); `selectedRobotId` stays the dashboard-context robot. No config, no cap.
- Per-robot frame: `robotFrames[rId] = robotsLocalizationData[rId]?.map?.frameId || DEFAULT_FRAME_ID`; transform via `findFrameTransform({robotDoc, systemDoc, from, to})` from `app/imports/shared/maps.js` (robot doc → system doc → identity → null).
- Skip semantics: a robot with a `null` transform is not rendered and is counted in `map.skippedRobots`; `map.noTransform` (banner + hidden interactions) is true only when the **selected** robot's transform is null and the transforms subscription is loaded.
- Publication `spatial_transformations` accepts `{ robotIds }` (array) and still `{ robotId }`; `canAccessRobots(userId, ids, ACCESS_LEVEL_VIEW)`; returns robot docs for the set + the system doc.
- Names: `RobotName` overlay text = `robotDetails.name || robotId`; layer id `robotNames`, label `Names`, default visible `true` (persisted per section like the other layers).
- Bandwidth: Mongo `localization` subscribed twice — `{ robotIds: <all except selected>, lowBandwidth: true }` and `{ robotIds: [selected], lowBandwidth }` — live MQTT (`ros/loc/data2`, `ros/loc/path`) only for `[selectedRobotId]`.
- Map choice logic and `DashboardDefinition` config unchanged. Copyright header on new files; tests imported from `app/tests/main.js`; commit per task with `Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>`; stage only the task's files (untracked root file `t` stays untracked).

```js
/** Which robots can be placed on a map in frame `toFrame` given their resolved transforms. */
function partitionByTransform({ robotIds, transforms = {}, toFrame }) {
  if (!toFrame) return { drawn: [...robotIds], skipped: [] };
  const drawn = robotIds.filter((id) => !!transforms[id]);
  const skipped = robotIds.filter((id) => !transforms[id]);
  return { drawn, skipped };
}
```
Export it. Publication (`publications.js`), replace the `spatial_transformations` handler:
```js
/**
 * Publish frame transformations relevant to a set of robots: each robot's overrides and the
 * system-wide set. Accepts `robotId` (legacy) or `robotIds`.
 */
Meteor.publish('spatial_transformations', async function ({ robotId, robotIds }) {
  const ids = isArray(robotIds) ? robotIds : (robotId ? [robotId] : []);
  if (!this.userId || ids.length === 0) {
    return this.ready();
  }
  if (!await new OroRoles().canAccessRobots(this.userId, ids, ACCESS_LEVEL_VIEW)) {
    return this.error(new Meteor.Error('Unauthorized'));
  }
  return SpatialTransformations.find({
    $or: [{ entityType: 'robot', entityId: { $in: ids } }, { entityType: 'system', entityId: '0' }],
  });
});
```

```js
/** Copyright header (Apache 2.0) */
/** Ids of every robot the user can see (the `robots` publication), stable across renders. */
import { useRef } from 'react';
import useRobots from './useRobots';

export function useFleetRobotIds() {
  const { robotsById } = useRobots();
  const ids = Object.keys(robotsById).sort();
  const ref = useRef(ids);
  if (ref.current.length !== ids.length || ref.current.some((id, i) => id !== ids[i])) ref.current = ids;
  return ref.current;
}
```

- [ ] **Step 2: `useFrameTransforms`** (in `useRobotMaps.js`, next to `useFrameTransform`)

```js
/** One transform per robot into frame `to` (robot override → system → identity → null). */
export function useFrameTransforms({ robotIds, robotFrames, to }) {
  const key = (robotIds || []).join(',');
  return useTracker(() => {
    if (!robotIds || robotIds.length === 0 || !to) return { isLoading: false, transforms: {} };
    const sub = Meteor.subscribe('spatial_transformations', { robotIds });
    const systemDoc = SpatialTransformations.findOne(SYSTEM);
    const transforms = Object.fromEntries(robotIds.map((id) => [id, findFrameTransform({
      robotDoc: SpatialTransformations.findOne({ entityType: 'robot', entityId: id }),
      systemDoc, from: robotFrames[id] || 'map', to,
    })]));
    return { isLoading: !sub.ready(), transforms };
  }, [key, to, JSON.stringify(robotFrames)]);
}
```

```js
function useMeteorLocalizationData({ robotIds, lowBandwidth, selectedRobotId }, cb = null) {
  const key = (robotIds || []).join(',');
  return useTracker(() => {
    if (!Array.isArray(robotIds) || robotIds.length == 0) return null;
    // Only the selected robot needs lasers and paths; everyone else is drawn from pose alone.
    const others = robotIds.filter((id) => id !== selectedRobotId);
    const subs = [];
    if (others.length) subs.push(Meteor.subscribe('localization', { robotIds: others, lowBandwidth: true }));
    if (robotIds.includes(selectedRobotId)) subs.push(Meteor.subscribe('localization', { robotIds: [selectedRobotId], lowBandwidth }));
    const p = RobotLocalization.find({ _id: { $in: robotIds } }).fetch().map((l) => { l.src = 'meteor'; return l; });
    const data = { isLoading: subs.some((s) => !s.ready()), localizationData: keyBy(p, '_id') };
    cb && cb(data);
    return data;
  }, [key, lowBandwidth, selectedRobotId]);
}
```
